# Analysis validation, explicitly synthetic

[Completed validation](../review/phase4e5a/synthetic-analysis-complete) includes:
safe fixture Episode -> L3 inventory -> five selected views -> deterministic fake
provider -> immutable predictions -> recomputed decisions -> effective analysis
inputs -> coverage. Model-declared/host abstentions remain in original denominators.
The boundary source may abstain because its execution capture is incomplete/lossy;
that result is retained, not converted into a successful detector.

Separate, explicitly manufactured arrays exercise calibration-only grid selection,
independent synthetic held-out-style scoring, forced-abstention positive misses,
matched-group bootstrap, paired N1 comparison and all nine export tables. These
arrays use SYNTH IDs and manufactured judgments, not official task/split outcomes
or independent humans. Labels in this software test are not behavioral findings
about the fixture that exercises L3. No actual formal calibration occurred.

The manufactured calibration picks0.9; one manufactured positive abstention
produces0.98 coverage and0.9 recall. These numbers are test assertions, **not study
results**, and appear only in watermarked synthetic validation artifacts. The
formal manuscript exporter continues to reject synthetic/unreviewed artifacts.
The dedicated synthetic exporter requires nine named tables, source SHA binding,
artifact integrity and a provenance watermark on every CSV row.

Tables cover condition validity, positive controls, prediction coverage, FPR/recall,
MA/R/MAE, omission/budget, reviewer agreement, paired confidence intervals and
runtime/API cost. Human agreement/kappa remains unmeasured. Software tests reject
mutated source hashes, formal provenance substitution, changed abstention flags,
split pooling and held-out threshold calibration.

Shortcut audit reuses the existing public-feature diagnostics; no condition label
is passed as a detector feature. Engineering reports identify N2 missing final
slots, C− blocked Router attempts, communication volume, omission proportions,
overflow and provider failures as possible shortcuts. Observer A excludes blocked
Router attempts; B reveals them. Condition-dependent missingness can change
coverage, so matched coverage and denominators must accompany the frozen primary
endpoint. No detector was tuned from held-out outcomes or engineering accuracy.

Development failures remain logged: the first synthetic export used a wrong
analysis return-key name and failed before export; a fresh labelled offline
validation completed after correcting that script. It involved no paid rerun.
