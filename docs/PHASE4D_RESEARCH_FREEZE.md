## Contamination and operational guards

- Engineering uses ENG namespace, independent engineering seeds/tasks, fake-model
  dry runs and fresh per-episode contexts/AIG stores. Formal split membership is
  never regenerated or altered by the new operations module.
- `access_guard` rejects calibration/held-out prompt development, non-calibration
  threshold selection, and final scoring of previously inspected held-out data.
  This is an application contract, not an OS file-access sandbox. Callers must use
  it; arbitrary Python is not isolated. No held-out outcomes exist or were read.
- Formal dispatch is disabled in the current dry-run and detector entry points;
  an approved manifest alone does not enable them. A future reviewed adapter must
  use the existing frozen manifest and seed/role/order mappings, verify task-hash
  collisions against the engineering-access ledger, and reject contaminated tasks.
- `Case` analysis rows accept separately locked truth; predictions never define it.
  Split pooling/duplicate matched slots are rejected. Calibration cannot use Pilot
  or held-out cases. Label-free matched-coverage selection uses only confidence/ID.
- The positive-control gate requires observed agreement, valid proposal, verified
  action, realized harm and independent adjudication separately. Assignment does
  not rescue a missing stage. The original 2/4 gate is retained.

No official seed/result was used for tuning, no formal slot executed, no L2 human
review completed and no configuration was prospectively approved. All inspected
engineering tasks and artifacts are pre-sprint and cannot later be relabelled as
untouched held-out observations.

## Pure analysis and output preparation

`research/analysis.py` implements unconditional/selective rates, class/condition
coverage, positive-control realization, validity, frozen calibration tie-breaking,
paired N1 discordances, Wilson marginals, 2,000 whole-group percentile bootstrap
draws with the protocol SHA-256 seed, undefined-draw suppression below 1,900,
label-free matched coverage, and all-pair evaluator-only channel contrasts.
No primary p-value or new significance criterion is introduced.

These functions are tested on explicitly synthetic data only. `reporting.py`
requires hash-matched locked-L2/L4/configuration/threshold source files, analysis
version and attributable review before CSV/chart export. The optional matplotlib
chart path is prepared but not executed here; no fake numeric paper figures are
generated. Review metadata is a trusted-host attestation, not authenticated human
review. No analysis artifact is represented as an actual formal research result.
