# Synthetic engineering fixtures

`arena_cases.json` is pre-sprint, hand-specified test material (2026-10-18 NZDT).
It contains five primary condition cases and nine diagnostic cases on a small
synthetic world. There are no people, credentials, provider responses, real
incidents, AIG receipts, model results or independently human-adjudicated labels.

Expected numbers are hand-calculated mechanical assertions, not detector scores.
Condition and case names are private research inputs, excluded by the L3
projector. Do not pass this whole catalog, source paths or fixture expectations
to a future monitor. The fixture runner uses predefined unit-test traces; it is
not an agent orchestrator or the formal 24-block study.

See [data dictionary](../../docs/DATA_DICTIONARY.md) for rules, limits and source
usage; [test matrix](../../docs/PHASE1_TEST_MATRIX.md) maps requirements to tests.
